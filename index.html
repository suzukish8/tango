    デッキ

    Windows版の tango1〜tango4 のように、単語ファイルごとに分けて学習できます。デッキごとに単語・復習の記録・進捗が別々に保存されます。

    今日の目標と進捗
    ファイルの読み込み・書き出し

    Windows版のファイルがそのまま使えます（words.txt / wrong_log.txt / progress.txt / setting.txt）。 読み込むときはファイル名で種類を判別します。データはこのブラウザの中にだけ保存され、サーバーには送信されません。

    を書き出す

    ブラウザのデータを消すと学習記録も消えます。ときどき書き出してバックアップしてください。

    単語を追加

    例文の中に英単語がそのまま入っていないと、[ **** ] の穴埋めになりません。 「something」のような置き換え語は使わず、例文に出てくる具体的な形を英単語欄に入れてください。 学習が進んだデッキに正解数0で追加すると、追加した単語ばかりが出題されるので、最頻値に合わせるのがおすすめです。

    単語の一覧
    #英単語和訳正解不正解

    メモ

    間違えた単語は自動で、出題中に「メモ」を押した単語も、ここにたまります。 書き出したメモは words.txt と同じ形式なので、別のデッキの単語ファイルにそのまま貼り付けられます。

      クリア
      使い方・ショートカット
      F1 / F2 / F3英訳 / 和訳 / 設定 のタブを切り替え
      F4答えの表示・非表示
      F5（英訳）解答欄の、正解と違うところを赤字で示す
      F6[ **** ] で穴埋めした英文の表示・非表示
      Escパス（わからないときに答えを見て次へ）
      1〜9, 0（和訳）選択肢を選ぶ

      ブラウザによっては F1・F3・F5・F6 がブラウザ自身の機能に使われることがあります。うまく動かないときは画面のボタンを使ってください。

      出題の決め方

      • 復習の時期になった単語があれば、いちばん遅れているものを優先して出します。
      • なければ、正解数がいちばん少ない単語の中からランダムに出します。
      • 不正解にした単語は、5問後 → 1日後 → 2日後 → 6日後 → 31日後 に復習します（復習に「正解」して「自信あり」と答えるたびに次の段階へ進みます）。
      • 復習の時期より前に出て正解したときは、段階は進みません。
